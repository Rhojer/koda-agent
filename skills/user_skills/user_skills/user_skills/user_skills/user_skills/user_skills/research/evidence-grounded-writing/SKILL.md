# Evidence-Grounded Thesis Writing

## When to Use
Use when drafting academic chapters requiring exact statistics from local workspace PDFs.

## Core Rules
1. **Zero Empty Rhetoric:** Never use vague claims without backing them with exact percentages or ranges from workspace files.
2. **Strict Document Grounding:** All epidemiological data must originate directly from shared PDFs.
3. **Continuous Flow:** Paragraphs between 5 to 11 lines, zero subheadings.
4. **Bracketed Citations:** Use `[Author]` format.
5. **Macro-to-Micro Problem Framing:** In the problem statement section, strictly focus on describing the problematic reality from global to local contexts (epidemiology, physiological limitations, clinical consequences) without drifting into justification or benefits of the study.
