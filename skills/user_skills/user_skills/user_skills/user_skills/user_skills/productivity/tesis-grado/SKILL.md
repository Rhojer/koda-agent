# Tesis de Grado — Guía y Asistencia Académica

Utiliza esta skill cuando el usuario DEScon esté trabajando en una tesis de grado, tesina, anteproyecto o disertación académica.

## Fases del Proceso de Tesis
1. **Definición del Tema, Título y Objetivos:**
   - Planteamiento del problema.
   - Objetivos generales y específicos.
   - Definición de variables e indicadores clave para la recolección de datos.

2. **Búsqueda y Filtrado de Antecedentes (con enfoque local/Venezuela):**
   - Búsqueda en fuentes de internet abiertas y accesibles desde Venezuela (Google Académico, Redalyc, SciELO, Dialnet, DOAJ).
   - Verificación estricta de rastreabilidad (URLs públicas o DOIs).
   - Coincidencia directa con los objetivos de la tesis y los indicadores del instrumento de recolección de datos.

3. **Fichaje y Resumen Analítico:**
   - Estructuración de fichas normalizadas: Autor, Año, Título, Fuente/URL, Objetivo, Metodología, Resultados y Aporte a la tesis.

4. **Estado del Arte y Marco Teórico:**
   - Síntesis organizada por categorías lógicas y redacción formal académica con adecuada citación.
